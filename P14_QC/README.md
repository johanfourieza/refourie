# The Quantitative Cape: a review of the new historiography of the Dutch Cape Colony
Fourie, J. (2014), The Quantitative Cape: a review of the new historiography of the Dutch Cape Colony, South African Historical Journal.

## Folders
- `original/`: released original data files: None. No input data are released for this paper.
- `repro_original/`: the surviving original code with path patches only (PATCHES.md).
- `repro_r/`: independent R rebuild.
- `modern/`: modern reanalysis (method_card.md).

## Running
Run from the repository root. `Rscript P14_QC/repro_r/01_clean.R` then `02_analysis.R` need the workbook listed below and, for one comparison, the claims file of paper P27_RW. They do not run with the released material. Aggregate comparison outputs are included.

## Data not included
- `Fourie Quantitative Cape.xlsx`: collation of series from Van Duin & Ross, Shell and others; obtain from Johan Fourie or the original publications.

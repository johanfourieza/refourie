# P09_FIM S6: deviations from, and implementation notes on, the frozen method card

Card: `modern/method_card.md`, v3, frozen at commit d59616d (A9). No analysis outside the card was added. Runtime was well under two hours, so no replication count was reduced. Every choice below was fixed in code before the full run. One debug run of `03_sensitivities.R` with 12 bootstrap draws (environment variable `P09_B`; default and final value 999) was used to check that the code ran end to end. It printed sensitivity output, but no choice was changed after it. **No item below was informed by results.**

**D1. Script layout and file names.** The card names `01_sample.R`, `02_primary.R`, `02b_truncreg_check.do`, `03_sensitivities.R`, `04_verdicts.R` and `modern/verdicts.csv`. Two scripts were added: `00_common.R` (shared likelihood, contrasts, critical values and §8B rules) and `05_figures.R` (forest plot). Following the task instructions, the verdict file is `output/verdict.csv` (verdict rows only). The §8B recruit-pattern findings are written separately to `output/findings_recruit_pattern.csv`, as §8 requires ("never merged with verdicts"). Pre-verdict checks are in `output/check_t2_reproduction.csv`, `check_sample.csv`, `check_s1_anchor.csv` and `check_stata_reconciliation.csv`.

**D2. Precision of the §4 reproduction check.** The card asks that the T2 total means reproduce `repro_r/output/table2_r.csv` to 1e-6, but that file stores means rounded to 2 dp. The check therefore compares the means rounded to 2 dp with `table2_r.csv` and rounded to 4 dp with `repro_r/results_r.csv` (both |difference| < 1e-6), together with the SDs (2 dp) and the counts (exact). All six cohorts pass.

**D3. Error of c_D.** `mvtnorm::qmvnorm` returns no error estimate. The reported error is the GenzBretz absolute error of P(max_j |Z_j| ≤ c_D), evaluated by `pmvnorm` at the solved c_D with the same settings and seed. It is 6.8e-6 < 1e-5, so maxpts was not increased.

**D4. Rebuilt sample with identifiers.** The S3 sample on D: carries no names or row identifiers, which §4B (candidate repeat pairs), S15c, S17 and S19 need. `01_sample.R` re-runs the rules of `repro_r/01_clean.R` (copied, unchanged) while carrying a row id and names, and stops unless the result is identical to `analysis_sample.rds` on all 14 analysis columns. It is identical. The WWII sheet has no names, so candidate repeat pairs exist only among colonial and WWI records. The S2-8 set is defined exactly as in `compare/s5_checks/s5_02_rebuild_checks.R` (67 rows in `Data`), and 26 of them are in the S3 sample. S17 drops those 26.

**D5. Tolerance of the S1 anchor check.** `s5_headline_proxies.csv` is rounded to 3 dp, so the 1e-3 tolerance is applied with an allowance of 5e-4 for rounding. The largest difference is 4.9e-4, which also passes at 1e-3.

**D6. Inference for sensitivities (card: "the §4 sample and inference unless stated").** Every T3 sensitivity reports the six Family T contrasts with its own simultaneous 95% intervals. c_T is recomputed by the rank rule of §4B, with expected rank 4, or 3 where b(1915–20) is not identified (S20, S21 without WWII; the contrasts that use it are reported as not computable). The §8B rule is applied to each as a reading aid (`sensitivity_findings.csv`), labelled "reported; does not vote". S12 uses HC1. S13 and S15b use the bootstrap covariance of the contrasts in the sup-t construction, and the unadjusted 95% percentile intervals the card names are printed in the `note` column. S14 uses −H⁻¹.

**D7. CR1 scale factor (S15a, S15c).** The card does not give the small-sample factor. G/(G − 1) is used, which is Stata's convention for `vce(cluster)` after ML.

**D8. Bootstrap mechanics (S13, S15b).** Replicate b uses the b-th L'Ecuyer-CMRG stream of a `nextRNGStream` chain started from `set.seed(20261011)`, so results do not depend on the number of workers (6, `parallel::parLapply`). S15b resamples force × enlistment-year groups with replacement and starts each fit at the full-sample estimates. A replicate that omits a force drops that force's column. Fits that fail the §4B convergence criteria, or that lack a cohort, are excluded and counted (`sensitivity_run_info.csv`).

**D9. S20 specification.** The card says "with region, occupation (S3 Armstrong coding), town flag and Attestation, as published". These covariates are added to the primary specification (force FE, growth dummies, c = 159.385, §4B sample rule), following the §5 rule that sensitivities use the §4 setup unless stated otherwise. The D7 weights are recomputed on the colonial + WWI S3 sample exactly as in `repro_r/02_analysis.R` and enter as weighted ML with a pweight-style sandwich. S20 is run four ways: with and without occupation, each unweighted and weighted.

**D10. Small details the card leaves open.** S18 uses the bins 1865–69, …, 1910–14 and 1915–20, with reference 1890–94. In S21 without WWI the force reference becomes SAC; cohort coefficients do not depend on the force reference. c_T is the type-7 sample quantile. Its Monte Carlo SE is half the width of the 95% order-statistic binomial interval, divided by 1.96. The §10.15 boundary flag marks a simultaneous-CI endpoint lying within (MC SE of c_T) × se of 0 or of ±0.5b₀. No contrast is flagged.

**D11. Disclosure in S25.** The height-by-age profiles within WWI and WWII use age bands (21, 22, 23–24, then five-year bands). The mean and SD are suppressed in any cell with fewer than five records, so no individual height is written.

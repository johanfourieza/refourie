# P05_DK S6: implementation deviations from the frozen card (v3, d59616d)

Logged under A5. "Results informed" means whether any corrected estimate, p-value or verdict had been seen when the choice was made. All choices below were made while writing `01_build.R` or the reporting code, before any corrected estimate existed, unless stated otherwise.

**D1. Rail distance for Port Shepstone (results informed: no).** Card §4A takes the authors' `log_rail_mdcentroid_to_nearestrail_km` for every undissolved unit. The authors computed it only on 1918 districts that received at least one 1970 district (`railways_1907_cleaning_ddk.R` runs on `findat`), so Port Shepstone has no authors' value. Without one, listwise deletion would drop the unit that the eligibility rule restores. The card's rule for dissolved units is applied instead: the authors' algorithm (CRS assignment at :29, existing lines at :32, centroid distance at :52–58) is re-run on the centroid of the 1918 polygon (6.014 km). The algorithm was first validated: re-run on the authors' own geometries, it reproduces their values for Cape, Durban, Paarl and Wellington to within 1e-6 km. `paarl_wellington` uses the same re-run (2.462 km), as the card specifies.

**D2. Sliver tolerance for "empty support" (results informed: no; coverage diagnostics seen, no estimate).** Card §4A sets a unit to missing when its support for a quantity is empty. The 1937 and 1918 layers were digitised separately, so their boundaries never coincide exactly. Seven units whose own 1936 sources are all missing (Elliotdale, Maphumulo, Mount Ayliff, Mpofana, Nqamakwe, Qumbu, Tsomo) still touch a neighbouring source through slivers of 1e-15 to 1.5e-5 of their area. With a strict "> 0" test, each would inherit that neighbour's unemployment rate. Support covering ≤ 0.1% of a unit's area is therefore treated as empty. The next-smallest partial support is 54% of the unit area, so any cut-off between 1.5e-5 and 0.54 gives the same classification. The mass-conservation check runs before this rule, because it tests geometry and double counting. Effect: H3 N = 199 instead of 206. The missing 1936 sources follow from the card's rule that one missing 15–64 age cell makes a district's denominator missing (8 districts: Mount Ayliff, Qumbu, Elliotdale, Nqamakwe, Tsomo, Mapumulo, Msinga, Ndwedwe), plus the two 1937 polygons with no 1936 district (Clocolan, Umlezi). The 1911 layer has no missing sources, so D2 does not affect it.

**D3. The −9999 sentinel (results informed: no).** `RSA_Pop_1904_70.shp` codes missing counts as −9999. Negative counts are read as missing, in line with the card's rule that missing values are never 0. Only Lesotho carries the sentinel, and the card excludes Lesotho, so this has no effect.

**D4. Walvis Bay (results informed: no).** Card §4A says every 1936 district is "asserted to match at least one 1937 polygon" and that "unmatched districts are listed". Walvis Bay, which lies outside the Union and outside every 1918 unit, matches none. It is listed and not attached, and the run continues. It cannot reach any 1918 unit.

**D5. Phillips match for polygons the authors' matching never reached (results informed: no).** The authors match Phillips rows to 1918 polygons only through the 1970 join, so Port Shepstone's polygon was never matched. The authors' own rule (`agrep` of the polygon's `OrgnlNm` against the Phillips names, accepting a single match) is applied to that polygon and returns "Port Shepstone" uniquely. Port Shepstone is the only such polygon.

**D6. Combined versus borrowed rates (results informed: no).** The build lists two Phillips rows mapped to more than one polygon: Paarl/Wellington and Umzimkulu (umzimkulu, lower umzimkulu). No name-based rule separates the two cases, because "Umzimkulu" appears in both polygon names. Lower Umzimkulu is classified as borrowed and ineligible, as card §4A identifies it explicitly. Paarl/Wellington is dissolved.

**D7. Reporting definitions not fixed by the card (results informed: no; none votes).**
- (a) Width ratio (§0, §4A): the published interval is the printed SE (10.933; 0.002) times 2·t(1 − α′/2, 205 − K), i.e. at the same Bonferroni level as the corrected interval.
- (b) Item 25 flag: the rejection rate at α′ exceeds α′ by more than two Monte Carlo SEs. σ² is the residual variance of the null two-way FE model, used as the marginal variance of the AR(1) process.
- (c) Item 15 counts "drops that would change the verdict category" by applying the full §8 H1/H3 table to each leave-one-out fit, with the primary inference.
- (d) Item 12 reports the `fwildclusterboot` p-value and its default 95% interval. Item 9 reports `conleyreg`'s z-test p. Item 11 computes its Conley 100 km t with the P28 implementation (great-circle distances, eigenvalue clipping), as card item 11 specifies "P28 mechanics".
- (e) Items 22–24 add the §4B randomization p(0) for the altered specification in the note column, next to the classical t-test. These are the primary inference applied to the listed sensitivity, not new analyses.
- (f) Item 2c: Port Shepstone has no covariates in the authors' construction, so it enters with its corrected covariates. For H3, the authors' 1936 crosswalk gives it no outcome either, so 2c-H3 equals item 1. Item 2d builds the dissolved unit in the authors' manner: summed authors' counts, the mean of the 1970 densities of both members, the re-run rail distance and Paarl's rain. Item 3 converts S3 rain from cm to mm, which does not change any focal coefficient.

**D8. Runtime.** The full pipeline (01–05) runs in about 3 minutes, well under 2 hours. No replication count was reduced. No package was installed. No fallback inference was triggered: both cross-section rows used CR2/BM. `conleyreg` is run with `ncores = 1`, because its multithreaded summation varied in the 14th digit between runs. With that setting, all five scripts regenerate their outputs byte-identically from clean Rscript sessions.

No deviation changed a verdict-deciding rule, margin or threshold.

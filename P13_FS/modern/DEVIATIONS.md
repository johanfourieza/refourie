# P13_FS S6 deviations from the frozen method card (commit d240e89)

No deviation touches a verdict rule, margin, primary sample or primary estimator. Total runtime is about 2 minutes, so no replication count was changed.

- **D1. Unmatched count.** §3 rule 1 says 265 U rows should be unmatched (citing F1). The data give 317 U rows (76 `mooc` values) that do not link to the 4,160 inventories. The 265 in F1 is the credit-side count, not the debt side. The figure is a reported count, not an assertion, so it changes nothing. Results-informed: no.
- **D2. Script layout and file names.** Sensitivities 1–12 are computed in `01_purpose.R`, not `03_sensitivities.R`, because they reuse the H1 bootstrap draws; `03_sensitivities.R` holds sensitivities 13–26 and H3-ext. The verdict table is written to both `modern/verdicts.csv` (card §6) and `modern/output/verdict.csv` (task specification), with identical content. Results-informed: no.
- **D3. Sensitivity 23 wild bootstrap statistic.** The card does not say which t-statistic the wild bootstrap studentizes. HC3 is undefined because one observation has leverage 1 (see results), so the bootstrap uses the HC1 t-statistic. Results-informed: yes (the leverage-one finding), but it affects a non-voting sensitivity only.
- **D4. Sensitivity 2 extra row.** With bonds left in Mixed, the 647 Bond/Bonds rows are also reported as their own competitor row (Δ = −3.76 pp). The card asks for "all Δ_c recomputed" over the 21 competitors; that row is added to make clear that, at Table 5's level of detail, the bond rows would exceed land. Reported, never voting. Results-informed: no.
- **D5. Sensitivity 16 logit inference.** The card does not specify the SE type for the participation logit. HC0 sandwich SEs are used. `glm` warns that some fitted probabilities are 0 or 1 (thin decade cells). Non-voting.
- **D6. Household clustering (sensitivities 12 and 24).** `household_iden` is unique per inventory (4,160 values for 4,160 inventories), so household clusters equal the primary inventory clusters (H1) and the HC case (H2). No separate household bootstrap was run; the count is reported.
- **D7. Verification-check targets that do not reproduce.** The S5 figures quoted in card §7 for the stored sample ("N 570", "conventional t 8.65") and the inheritance-excluded variant ("N 564") do not reproduce: listwise deletion drops 5 rows with missing `year_string`, giving N 565 and 559, and the conventional OLS t is 8.43. The coefficients (0.0826, 0.0712) and the HC1 t (7.12) reproduce exactly; the 8.65 appears to be the ML-Tobit t that s5_09 printed. This is a reporting discrepancy in S5, not a change to the card.

# P04_CF S6: deviations from, and implementation notes on, the frozen method card

Card: `modern/method_card.md`, frozen at commit 3c01885. No analysis outside the card was added. Runtime was short (about 2.5 minutes per full bootstrap on 30 workers), so the nested draws were **not** reduced: B = 4,999 and nested 199 throughout. Items D1–D4 are places where the card left an implementation detail open; D5 is the only point where the executed rule departs from the letter of a cited file. No result informed any of these choices: all were fixed in the code before the first full run, and none was changed afterwards.

**D1. Father clusters for the 159 duplicate pairs (departure from the letter of `s5_link.R`; forced).** `s5_link.R` gives a singleton cluster to the 318 rows whose key matches two 2017 records with different father ids. Those rows are the 159 duplicate son pairs (finding N4): the two candidate records have identical occupation strings (verified, `output/build_checks.csv`). Two records of one son with different father ids would otherwise sit in separate clusters, which understates dependence. The pipeline therefore uses the S5 cluster construction (`s5_clusters.R`, which reuses the `s5_link.R` key and candidate rule and merges father ids within each `s5_duplicates.R` group by union–find). Every 2016 row links, so the card's singleton rule for unlinked pairs never binds. Result: 5,261 father clusters on the full file; 5,114 in the primary sample.

**D2. Share recomputed "within each bootstrap draw" (card §4.3).** The share enters only Model 3 (I2), whose inference is CR1 by the card's own §4.5. No bootstrapped statistic (Δ, D) uses the share, so the in-draw recomputation is vacuous. The share is rebuilt once on the analysed sample: the % of sons in the period whose father is in the class, rounded to 2 dp like the original labels (`origin_occ_group_share` logic; decoding verified against the 2016 labels, 0 mismatches).

**D3. Percentile-t details.** Each outer draw is studentised by the SD of its 199 nested draws. The SE of the original estimate is the SD of the 4,999 outer replicates. Quantiles use type 6. The two-sided p is 2·min{(1+#t*≥t₀), (1+#t*≤t₀)}/(B+1), t₀ = θ̂/SE, which inverts the equal-tailed interval. TOST: p_L = (1+#t* ≥ (D̂+5)/SE)/(B+1), p_U = (1+#t* ≤ (D̂−5)/SE)/(B+1), p_TOST = max(p_L, p_U), which enters Holm as the I4 test. Each outer draw has its own L'Ecuyer-CMRG stream (`nextRNGStream` chain from seed 20261011), so results do not depend on the number of workers. Every sample reuses the same streams (common random numbers). Where two samples have the same number of father clusters (primary and S2), the same clusters are therefore drawn by position. A clean rerun reproduced `primary.csv`, `verdict.csv` and `sensitivities.csv` byte for byte. The 0.5 rule is applied per table (P or Q) only when that table has a zero cell. Raking: row then column step, convergence when max |row sum − target| < 1e-10, at most 1,000 iterations. A draw is discarded and counted if raking fails, including a draw with an empty Slavery margin (`output/bootstrap_failures.csv`). There were no outer failures and 46 inner failures in the primary run (out of 994,801 inner draws).

**D4. CR1 and verdict mechanics.** CR1 = `sandwich::vcovCL(type = "HC1")`, that is G/(G−1)·(N−1)/(N−K), with normal reference. I4 rule 1 ("TOST rejects (CI within ±5 pp)") is applied as Holm-adjusted p_TOST < 0.05. Whether the Bonferroni CI also lies within ±5 pp is recorded in the rule text; in the primary it does. Estimates and CI bounds are rounded to 3 dp before the comparisons with the thresholds (card §7).

**D5. Sensitivity 6 (diagnostic) scope.** "Original coding with the primary inference" replaces card step §4.2 only: the son and father classes are those of the 2016 analysis file (the published coding). Sample (1800–1909), the decoded and rebuilt share, and the inference are as in the primary. Its point estimates therefore differ from the original-code values through the 1910 rule and the share decoding as well as the inference; the original-code values themselves are shown in the forest plot.

**Sample note.** Primary N = 9,230: 9,494 pairs, minus 158 that lose their only coded term when "century" is removed, minus 106 born in 1910. No covariate has missing values.

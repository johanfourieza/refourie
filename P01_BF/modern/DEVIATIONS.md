# P01_BF S6: deviations from, and implementation notes on, the frozen method card

Card: `modern/method_card.md`, frozen at commit d59616d (v3). No analysis outside the card was added. Runtime was well under two hours, so no replication count was reduced. All choices below were fixed in code before the full run. A test run with B = 40 pairs-bootstrap draws was used to debug the code; it showed sensitivity output, but no choice was changed after it except the bug fixes listed in D10. **No item below was informed by results.**

**D1. Script layout (forced by code sharing).** The card names `01_t6.R`, `02_t9.R`, `03_sensitivities.R` and `04_verdicts.R`. Two scripts were added: `00_common.R` (shared helpers, sourced by the others) and `05_figures.R` (forest plot). The pre-verdict checks are written to `output/checks_t6.csv` (G1–G4, run in `01_t6.R` before any corrected estimate) and `output/checks_h3.csv` (G1 Khoesan counts and G5, run in `02_t9.R` before the bootstrap).

**D2. CRAN packages installed.** `detectseparation` 0.4.0 (with `ROI`, `ROI.plugin.lpsolve`) and `brglm2` were not installed; the card requires both (§4A, sensitivity 8). They were installed from CRAN into the user library (`C:/Users/johanf/AppData/Local/R/win-library/4.5`). `install.packages` downloaded the binaries into the R session's temporary folder on C:, which is R's default. No data passed through C:. Versions are in `sessionInfo.txt`.

**D3. Interval level and reference distribution for sensitivities (card silent).** Every sensitivity interval uses the primary's Bonferroni level, 1 − 0.05/9: est ± t(G − 1, 1 − 0.05/18)·SE for clustered T6 and H3 variants, a normal quantile for the non-clustered vcovs of sensitivity 14, Welch df for the Welch test (16), and z at 1 − 0.05/18 for the Newcombe interval (16). Sensitivity p-values are unadjusted.

**D4. Sensitivities that re-fit on a different sample or coding (5–11, 13, 17–19).** The profile x̄ᴺ is the mean of the non-origin regressors in that model's own estimation sample, as in the primary definition (§3); it is held at the full-sample value only in the resampling sensitivities (15, 20, 21), as the common rules require. A subsample with an absent origin group drops that level, and its rows are reported as missing. `detectseparation` runs on every re-fit. When it finds an infinite coefficient, the row's status says so and lists the infinite terms; the finite-iteration glm numbers are still printed but carry no meaning. Sensitivity 11 (audit decomposition) applies the rebuild codings to the primary specification (corrected contrast, CR1), following §5's "varies one item from the primary unless stated". The rebuild codings come from `D:/…/P01_BF/repro_r/_scratch/p01_full.rds`, row-aligned to `data.dta`, with the group mapping of `compare/s5_checks/s5_01_T6_decomp.R`.

**D5. Sensitivity 7 (LPM) -rel rows.** The card specifies the LPM for the point contrast. The -rel analogue is the log ratio of the LPM-predicted ABCC levels at the same profile, ln((x̄ᴺ'b + b_g)/x̄ᴺ'b), with a delta-method CR1 SE.

**D6. Sensitivity 13.** The OLS with controls and the T8 col 1 difference (`ko_mid − ko_early` from the l.1667 LPM on all 1,802 records) use CR1 by `source` with t(G − 1) (G = 34 and 43). The logit MEM uses the delta method with CR1 by `source`, t(33).

**D7. Sensitivity 15 (pairs bootstrap) mechanics.** Draw b uses its own L'Ecuyer-CMRG stream, the b-th element of a `nextRNGStream` chain started from `set.seed(20261011)` in the master process. Results therefore do not depend on the number of workers or on scheduling (8 workers, `parallel::parLapply`). Each draw resamples the 43 volumes with replacement. Percentile endpoints use `quantile(type = 7)` at 0.05/18 and 1 − 0.05/18. The reported "se" is the SD of the defined draws. Reasons for undefined draws are in `output/s15_undefined_reasons.csv`.

**D8. Sensitivities 20 and 21 (deletions).** The card asks for "the number of deletions that would change the verdict category" but does not give the inference for a deletion. Each deletion re-runs the primary inference on the remaining data. T6 rows: CR1 by `source` with t(G − 2) = t(41) and the full-sample profile. H3: the WCR bootstrap (B = 9,999, seeds reset, with the §4B Monte Carlo rule) when the deleted volume holds Khoesan of cohorts 1–2; otherwise H3 is unchanged and keeps its primary p. Then come Holm over the nine rows (an undefined row enters at p = 1 and is not-testable) and the §8 ladders, including H2-all. The CV3 jackknife (21) for H3 uses the 34 volumes in the H3 sample (G = 34, t(33)), because deleting a volume with no Khoesan leaves D unchanged; the T6 rows use all 43.

**D9. fwildclusterboot message.** `boottest` notes that it "performs best" when sign_level × (B + 1) is an integer. With sign_level = 0.05/9 and B = 9,999 or 99,999, it is not. The card fixes both values, so neither was changed. The message concerns the interval only, which is reported and not used for the verdict.

**D10. Bug fixes during development (before the full run).** (a) The separation-block flags were coerced from a 1-D table to a named logical vector. (b) Reason codes were added to undefined resamples. Neither fix changes an estimate.
